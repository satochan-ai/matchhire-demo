# MatchHire

🔗 **デモ（GitHub Pages）**: https://satochan-ai.github.io/matchhire-demo/

> デモ版はダミーデータ（mock固定）で動作します。個人情報・実データは含まれません。

**候補者・求人・応募・面接・評価を横断して確認できる、採用状況可視化デモです。**

スカウト送信から内定・入社まで、採用活動の情報をひとつの画面で確認できます。
「どこで候補者が離脱しているか」「誰のスカウトが効いているか」「面接評価はどうだったか」が、すぐにわかります。

---

## こんな課題を解決します

| よくある悩み | MatchHire でできること |
|---|---|
| 候補者・求人・応募の情報がバラバラに管理されている | 候補者・応募・面接履歴を一元管理 |
| スカウトをたくさん送っているのに面接につながらない | ファネルのどこが詰まっているか診断 |
| 担当者によって採用結果がバラバラ | 担当者ごとの応募・面接・内定状況を数字で比較 |
| なぜ不採用・辞退になったのか分析できていない | NG理由を集計してグラフで可視化 |
| 面接評価が候補者情報と切り離されている | 候補者詳細から面接評価まで迷わず遷移できる |
| PCだけでなくスマートフォンでも状況を確認したい | 主要画面がスマートフォンにも対応 |

---

## 主な機能

### 📊 採用ダッシュボード（採用ファネル全体を一画面で）

```
スカウト送信 → 開封 → 返信 → 有効応募 → 面接 → 内定 → 承諾 → 入社
```

8段階の採用ファネルを一覧表示し、期間フィルタ（今日／今週／今月／全期間）で絞り込めます。

**ボトルネック診断**では、現在の最優先課題を特定し、対応の方向性を提示します。
あわせて、ファネルの状況やNG理由の傾向から気づきを整理する
**ルールベースの採用インサイト**（AI APIは使用していません）も表示します。

---

### 👤 候補者管理（進捗を一覧で把握）

- 候補者一覧を検索・絞り込みして表示
- 候補者名をクリックすると詳細ページへ遷移
  - 基本情報・応募状況・面接履歴・接触履歴がすべて1ページにまとまっています

---

### 📋 応募管理（どの求人に誰が応募しているかを把握）

- 応募一覧を表示（求人名・応募日・応募経路・有効応募フラグ）
- 応募経路・有効応募・ステータスをかけ合わせた絞り込みが可能です

---

### 💼 求人管理（求人ごとの採用状況を比較）

- 求人一覧を検索・絞り込みして表示
- 求人名をクリックすると、求人別KPI・採用ファネル・応募者一覧を確認できます

---

### 🧑‍💼 担当者分析（担当者ごとの状況を比較）

- 担当者別のサマリーと比較グラフ（件数／率の切り替え可能）
- 一覧テーブルで担当者ごとの応募・面接・内定状況を比較できます

---

### ❌ NG理由分析（なぜ落ちているのかを集計）

- 総括サマリー・理由別ランキング・構成比ドーナツチャートで可視化
- 求人・担当者で絞り込んで深掘りできます

---

### 🗣️ 面接評価（面接結果をその場で記録）

- 候補者・求人・面接情報のサマリーを確認しながら評価を入力
- 技術評価・コミュニケーション評価・志向性一致（各1〜5）、総合評価（A〜D）、結果（通過／不採用／保留）を選択
- 結果が「不採用」のときだけNG理由を選択
- 懸念点・評価コメント・次回アクションをコメント欄に入力

入力内容はその場でライブプレビューに反映されます。
**保存操作はデモ表示のみで、実際のデータ更新は行われません**（ページを再読み込みすると元の値に戻ります）。

## 画面の使い方

起動後、ブラウザで以下のURLにアクセスしてください。
左側のメニューからも各ページに移動できます。

| ページ | URL | 見どころ |
|---|---|---|
| ダッシュボード | `/matchhire/dashboard` | ファネル全体・ボトルネック・採用インサイト |
| 候補者管理 | `/matchhire/candidates` | 候補者一覧・検索・絞り込み |
| 候補者詳細 | `/matchhire/candidates/1` | 応募状況・面接履歴・接触履歴 |
| 応募管理 | `/matchhire/applications` | 応募一覧・応募経路／有効応募／ステータス絞り込み |
| 求人管理 | `/matchhire/jobs` | 求人一覧・検索・絞り込み |
| 求人詳細 | `/matchhire/jobs/j1` | 求人別KPI・採用ファネル・応募者一覧 |
| 担当者分析 | `/matchhire/owners` | 担当者別サマリー・比較グラフ |
| NG理由分析 | `/matchhire/ng-reasons` | 総括サマリー・理由別ランキング・構成比 |
| 面接評価 | 候補者詳細の面接履歴から遷移（例：`/matchhire/interviews/i1/evaluation`） | スコア・結果・NG理由・コメントの入力とライブプレビュー |

### はじめて触るときの順番

1. **ダッシュボード** を開き、ファネルとボトルネック診断を確認
2. **候補者一覧** から候補者を選ぶ
3. **候補者詳細** で応募状況・面接履歴を確認
4. 面接履歴から **面接評価** 画面を開き、スコアや結果を入力してライブプレビューを確認
5. **求人管理・担当者分析・NG理由分析** で他の切り口から状況を確認

## 起動方法

**事前に必要なもの：** [Node.js](https://nodejs.org/ja/) バージョン 18 以上

```bash
# ① リポジトリをダウンロード
git clone <リポジトリURL>
cd match-hire

# ② 必要なファイルをインストール（初回のみ・1〜2分かかります）
npm install

# ③ 起動
npm run dev
```

起動後、ブラウザで **[http://localhost:3000](http://localhost:3000)** を開くとダッシュボードが表示されます。

> ポート3000が使用中の場合は、任意の空きポートを指定できます。
> ```bash
> npm run dev -- -p 3004
> ```

## データモード

MatchHire は、データの取得元を3つのモードから選べる設計になっています。
設定は `.env.local` というファイルの1行を書き換えるだけです。

| モード | 設定値 | 内容 | 用途 |
|---|---|---|---|
| **モック**（初期設定） | `mock` | ツール内蔵のダミーデータ | デモ・動作確認 |
| **CSV** | `csv` | `data/` フォルダのCSVファイル | 自社データで試したいとき |
| **Google Sheets** | `sheets` | Googleスプレッドシートと連携 | 本番運用（準備中） |

```
# .env.local（プロジェクトのルートフォルダにあります）
NEXT_PUBLIC_DATA_SOURCE=mock
```

> **CSVモードの使い方**は [`docs/csv_operation_guide.md`](docs/csv_operation_guide.md) に詳しく書いてあります。
> Excelで作ったデータをCSV形式で書き出して `data/` フォルダに置くだけで、自社のデータで動かせます。

## デモ上の制約

- 画面上の人名・スキル・会社情報はすべて **架空のダミーデータ** です（実在する人物・企業・求人とは一切関係ありません。個人情報は含まれていません）
- デフォルトではモックデータ（`mock`モード）で動作します
- **面接評価は入力・プレビューまで体験できますが、保存は行われません。** 保存ボタンを押しても画面上の表示だけが更新され、ページを再読み込みすると元の値に戻ります
- Google Sheets連携（`sheets`モード）は公開デモでは無効です

```

├── src/
│   ├── app/            # 各ページ（Next.js App Router）
```

`src/lib/dataSource.ts` の `getDataSource()` が `NEXT_PUBLIC_DATA_SOURCE` を読み取り、
各リポジトリ（`src/lib/repositories/`）がモード別の取得ロジックに分岐します。
